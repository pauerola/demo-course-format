# HPC for AI - Part 1: Quarto site proposal

1. Install Quarto (https://quarto.org/docs/get-started/).
2. `quarto preview` in this folder to view the site, `quarto render` to build it into `_site/`.
3. Section files live in `pages/`. Section 4 (`pages/04-one-gpu.qmd`) is the worked example of the layout. The other section files are stubs to fill in.
4. Add `slides.html` (or change the link in `_quarto.yml`) and `hpc-for-ai.ipynb` for the Slides and Notebook buttons.
5. The accent red in `custom.scss` (`$primary`) is an assumed Bristol red; replace it with the exact value.
